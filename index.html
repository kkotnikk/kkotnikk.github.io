Sistema web · Operação logística

Consulta
Regiões

Uma ferramenta criada para apoiar a rotina de coletas de uma transportadora: encontrar a região de um bairro, consultar rotas e manter as informações atualizadas em um só lugar.

HTMLCSSJavaScriptSupabase
Abrir projetoEntender a solução
Exemplo de consultaRegiões / SP
ResultadoDigite um dos bairros do exemplo.

Experimente: Vila Maria, Tatuapé, Santo Amaro ou Campinas.

01 / Problema

Informação espalhada

Consultar regiões e acompanhar rotas exigia procurar informações em lugares diferentes durante a operação.

02 / Solução

Uma consulta rápida

Busca de bairros, cadastro de regiões, cartões de rota e confirmação de retorno em uma interface para computador e celular.

03 / Construção

Dados que podem evoluir

Supabase para guardar registros e permitir atualizações sem editar o código a cada novo bairro.
